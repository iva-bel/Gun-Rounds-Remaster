# Gun Rounds Remaster
Привет, этот проект является переосмыслением оригинального проекта ["Gun Rounds"](https://blabberf.itch.io/gunrounds) за авторством Blabberf. В этой версии будет добавлены те вещи, которые оригинальный разработчик не релиозовал ( к примеру критический удар и урон от огня ) и будут добавлены мои идеи ( бестиарий, новые оружия/предметы и многое другое ). Я постараюсь сохранить  тот стиль и геймплей, который вносил оригинальный разработчик.
# Что на данный момент есть?
**1.** Четыре разных режима.

**2.** Десятки оружия и предметов ( в будущем добавятся и те, кто в релиз не попал ).

**3.** Локализация ( русский, английский, итальянский).

**4.** Торговец, которые продает вам предметы.

# Gun Rounds Remaster
Hello! This project is a reimagining of the original game ["Gun Rounds"](https://blabberf.itch.io/gunrounds) by Blabberf. This version incorporates features that the original developer did not implement (such as critical hits and fire damage), alongside my own ideas (a bestiary, new weapons/items, and much more). I aim to preserve the style and gameplay established by the original developer.
# What is currently included?
**1.** Four distinct game modes.

**2.** Dozens of weapons and items (with more to be added, including content that didn't make it into the original release).

**3.** Localization (Russian, English, and Italian).

**4.** A merchant who sells you items.
